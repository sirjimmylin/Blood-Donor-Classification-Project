Challenges & Insights

Key obstacles encountered and how they were addressed

⚖️ Severe Class Imbalance

87% of samples were healthy Blood Donors. Addressed with stratified splitting, balanced class weights, and F2-weighted evaluation that accounts for class distribution.

🔍 Missing Data

5 of 12 features had missing values. Strategy: XGBoost handled NaN natively, while LR/SVC used reduced-feature subsets without missing data.

🧬 Clinical Relevance

Feature importance aligned with clinical knowledge — liver enzymes (AST, ALT) and cholinesterase ranked highest, confirming the model learns biologically meaningful patterns.

📊 Metric Selection

Standard accuracy would be misleading (~87% from majority class). F2-weighted score properly penalizes missed hepatitis diagnoses while still considering false positive costs.
